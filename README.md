# Extrator de PKG - Wallpaper Engine

UI simples para extrair imagens e texturas de arquivos `.pkg` do Wallpaper Engine.

## Funcionalidades planejadas
- Selecionar arquivos `.pkg` ou a pasta do Workshop do Wallpaper Engine.
- Listar arquivos e imagens/texturas contidas no pacote.
- Extrair imagens em formatos padrão (PNG, JPG).
- Interface gráfica simples e amigável.
